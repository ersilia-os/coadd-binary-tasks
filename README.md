# CoADD  Binary Tasks

Binary classification tasks for antimicrobial drug discovery, derived from the [CO-ADD](https://co-add.org) dataset.

## Data

Raw data, processed files, and model outputs are not stored in this repository. They are available on the Ersilia EOSVC storage. Download them before running any script.

- CO-ADD: full dataset from [db.co-add.org/downloads](https://db.co-add.org/downloads/), place under `data/raw/coadd/`
- SPARK: MIC and accumulation data from the CDD Vault, place under `data/raw/spark/`. Processed but not used for modelling
- ChEMBL sample: random SMILES used for cross-model correlation, place at `data/raw/chembl_random.csv`
- EU Openscreen: validation sets from EU-OpenScreen, curated in this [repository](https://github.com/ersilia-os/eu-openscreen-antimicrobial-tasks)

## Tracking

- **Git** — code only (scripts, notebooks, src)
- **Eosvc** — data and output artefacts in eosvc (private)

## Pipeline

See [`scripts/README.md`](scripts/README.md) for a description of each script and execution order.

Config files under `config/` were generated by `00_prepare_configs.py` and then manually edited to assign pathogen codes, strain codes, and binarisation cutoffs. The reviewed versions live in `config/manual/`.
